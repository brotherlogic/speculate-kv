# Speculate KV

![Spec Alignment](https://img.shields.io/badge/Spec%20Alignment-0%25-red)

Key-Value service contract and implementation managed by [Speculate](https://github.com/brotherlogic/speculate).

## Overview
This repository defines the behavioral specification ([specs/kv.md](specs/kv.md)) and Protobuf service contract ([proto/kv/v1/kv.proto](proto/kv/v1/kv.proto)) for a Key-Value storage service under Spec-Driven Autonomous Verification (SDAV).
